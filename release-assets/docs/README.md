## Recommended reading paths

- **First-time user:** root `README.md`, root `QUICKSTART.md`, then `PBF-User-Guide.md` as needed.
- **Understand the framework:** `PBF-Project-Overview-and-Method.md`.
- **Understand implementation:** `PBF-Architecture-and-Technical-Reference.md`.
- **Maintain or package PBF:** `PBF-Maintainer-Handbook.md`.
- **Check release claims:** `PBF-Release-Notes-and-Verification.md` and `PBF-Quality-Assurance-and-Review-Policy.md`.

The agent package also contains `AGENT-OPERATING-INSTRUCTIONS.md` and `AGENT-STARTUP-PROMPT.md`. Those are operational setup instructions for an agent, not additional general-purpose user documentation.
