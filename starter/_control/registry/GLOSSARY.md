# GLOSSARY.md — Canonical vocabulary

Define terms with a stable meaning once and use the same wording throughout. Put aliases in the register so ambiguous synonyms can be replaced.

| Term | Definition | Aliases to avoid | Defined in |
|---|---|---|---|
| Planning baseline | Owner-approved, versioned set of project docs that defines intended product, constraints and implementation approach. | final spec (unless referring to a particular artifact) | `_framework/WORKFLOW-PLAN.md` |
| Source of truth | The one canonical location that owns a fact, rule, metric or decision. | duplicate authority | `OPERATING-MANUAL.md` |
| Phase gate | Explicit review of evidence and exit criteria before progressing. | milestone approval (unless distinct) | `_framework/WORKFLOW-PLAN.md` |
| Ripple queue | List of documents invalidated by an upstream change and awaiting revision/reapproval. | affected docs list (use same term consistently) | `_framework/PROTOCOLS.md` |
| Walking skeleton | Earliest thin end-to-end path that proves critical architecture and delivery mechanics. | — | `_framework/WORKFLOW-PLAN.md` |
