# Research Notes

Use this directory for supporting research notes that do not belong in a canonical project document. Give each note a descriptive filename and record:

- Research question and why it matters to the project.
- Date accessed and relevant publication/update date.
- Source name and direct URL for each material claim.
- Key findings, limitations, assumptions and conflicting evidence.
- Implications for project decisions or requirements, clearly separated from source facts.
- Whether the result is provisional or has been incorporated into a canonical document.

Prefer authoritative primary sources for technical specifications, laws, security guidance and vendor capabilities. Recheck information that can change. A research note is supporting evidence, not an approval or a substitute for the source document.

Supporting files may be stored under `docs/_assets/attachments/` when that optional asset directory is needed. Canonical project decisions belong in [`_control/registry/DECISIONS.md`](../../../_control/registry/DECISIONS.md), not in an unreviewed research note.
