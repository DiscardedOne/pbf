# DOC-CATALOG.md — Canonical document catalog

The catalog defines reusable checklists for common document types and powers the `scaffold` command. Each catalog row has a `Template` mapping to a file under `_framework/templates/`; `document` is the general default, `D0.02` maps to `adaptive-document-architecture`, and component records map to `component-spec`. Catalog `Depends on` values are content dependencies only; structural review candidates are derived separately from the accepted adaptive architecture. Add and validate a new template when the project's tailored architecture needs a specialized document family. It is **not the project's required final structure**. In P0, follow `_framework/ADAPTIVE-DOCUMENT-ARCHITECTURE.md` to design and review a project-specific tree, document families, granularity, phase fit, dependencies, diagrams and coverage map. Add, rename, merge, split, move or exclude groups as justified. Update the manifest, template mappings and validation expectations when tailoring. Every critical concern must be covered somewhere, explicitly N/A with rationale, or tracked as unresolved/deferred with an owner and trigger. The structure is approved provisionally and revisited when material project learning warrants it. The manifest stores **Applicability** separately from workflow status and a **Profile tier** (`lite`, `standard`, `exhaustive`). Only active, in-profile documents are eligible for scaffolding. Conditional items require an explicit decision in D0.02 before activation; deferred/excluded items are not scaffolded. Profiles are minimum-depth tiers: Lite includes `lite`; Standard includes `lite` + `standard`; Exhaustive includes all tiers. Scaffold only the next useful slice by default.

## Document size

- `S`: focused decision or compact reference.
- `M`: one significant topic, normally multiple sections and/or diagrams.
- `L`: complex topic requiring several subsections, many traceability links, or a folder of repeatable specs.

The size is a planning weight only. Split documents that become difficult to review; preserve the original path as an index where feasible.
